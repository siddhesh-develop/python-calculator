# Python Calculator (with Anger Issues) 🤬🧮

Welcome to my first Python project! It does basic math (+, -, *, /), but more importantly, it has zero tolerance for stupidity. 

## 🚨 The "Anti-Idiot" Protection System
When building this, I realized that users are unpredictable. They might type `5`, they might type `10`... or they might be a Kevin and type `"hello"` into a math prompt. 

Instead of letting the program crash with a boring red error screen, I built a `try/except` block. If the user types a word, the calculator will process their nonsense and hit them with a custom roast before kicking them out.

### 🔥 Example Outputs when the user types "hello":
* *User:* `hello`
* *Calculator:* `"🚨 Error: Sir, this is a Wendy's. 🍔 Please enter a valid number, not your deepest thoughts! 💅"`

## 🛠️ How to run
Run `python calculator.py`. 
*Type a number to do math.* 
*Type a word to get emotionally destroyed.* 💀
